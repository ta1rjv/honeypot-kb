Attack Patterns

Patterns the platform recognizes, with the evidence that shows them working. Source of every entry is stated; this directory never contains captured malware, real attacker credentials beyond category level, or secrets.

Status of the evidence:

  • Simulated (2026-10-07): reproduced in a lab with RFC 5737 documentation addresses. Not yet observed from real internet attackers.
  • Observed (2026-10-08): first real internet traffic captured on the production VDS. See 2026-10-08-observed-ssh-loader-and-worm.md (Go SSH loader capability probe, dota/outlaw-family SSH worm key+config drop, SFTP sshd upload). Full triage of the resulting 13 alerts: docs/reports/2026-10-08-critical-alerts-triage.md.
