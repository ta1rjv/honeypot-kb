Architecture Decisions

Each published decision has a full record in the library; this page summarizes the outcome and the status. Decisions about operating this specific deployment are not published. The index is docs/decisions.

ADR Decision Status
0001 Cowrie as the SSH honeypot. Medium interaction, emulated shell, SFTP/SCP capture, JSON log and TTY logs; compared with other honeypots in the research. Realistic enough for automated attackers, detectable by skilled ones. Accepted 2026-10-05
0002 Direct tcp/22 binding with a single capability and a foreground process under systemd, after a daemonizing start caused a restart loop. No NAT rules. Accepted 2026-10-06
0003 Containment by user id, no honeypot egress at all. Output policy drop and the honeypot user dropped first, even on loopback. Attacker downloads fail by design; uploads are still captured. Accepted 2026-10-06
0004 SQLite now, PostgreSQL-compatible schema. Portable types, WAL mode, versioned migrations, deterministic ids for idempotent ingest. PostgreSQL itself is not tested. Accepted 2026-10-06
0005 FastAPI and WebSocket backend serving the React dashboard from one process; WebSocket authentication by first message, no CORS. Accepted 2026-10-06
0006 Offline release tarball with a wheelhouse, built on a workstation; the host installs without internet and keeps the previous release for rollback. Accepted 2026-10-06
0007 IP intelligence from DNS-based sources (Team Cymru, switchable reverse DNS, optional local database); no API keys; never treated as identity. Accepted 2026-10-06
0008 Evidence and confidence model. Observed versus derived evidence; Suspected < Likely < Observed < Confirmed; every classification lists evidence and event ids. Accepted 2026-10-06
0010 Keep all captured logs for research. Retention set to an effectively unlimited window on both database and raw files; disk alerts stay active. Accepted 2026-10-08
0011 Opt-in webhook alerts. One IPv4 address and port for the backend user, signed, no backlog. VALIDATED on a disposable VM; production use NOT VERIFIED. Accepted 2026-10-11
0013 Alert suppression rules. Demote or hide known noise at the single alert choke point; events and sessions untouched, alerts never deleted. A seed rule for the known loader probe is active on production (MEASURED 2026-10-16). Accepted 2026-10-15
0015 Telegram and SMTP receivers on the shared notifier; secrets only in the environment file, STARTTLS or TLS only, per-channel threshold, rate limit and digest. Supersedes the "SMTP deferred" part of ADR 0011. Tested against local fakes; VM validation NOT VERIFIED. Accepted 2026-10-15
0018 External reputation enrichment and its egress. Five fixed providers, pinned addresses, one narrow rule each for the backend user, informational results only. Foundation and one pilot client IMPLEMENTED on a work branch; not released; other providers PLANNED. Accepted 2026-10-16

Reading the status column

"Accepted" means the owner approved the decision. Implementation and validation levels are stated separately in each record and in Operations history; a decision can be accepted while its validation is still NOT VERIFIED.
