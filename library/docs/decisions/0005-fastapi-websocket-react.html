ADR 0005: FastAPI + WebSocket backend, React dashboard served by the backend

Status: accepted (2026-10-06)

Decision: one Python process (FastAPI/uvicorn) runs the collector, enrichment, housekeeping, REST API, WebSocket and serves the built React (Vite, TypeScript) dashboard from the same origin. WebSocket auth uses a first message with the JWT (never the URL). No CORS.

Consequences: one service to operate; the dashboard build happens on the workstation (no Node.js on the VM).
