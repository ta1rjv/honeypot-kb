Assumptions

source: docs/ASSUMPTIONS.md 1 sections

Values chosen without production measurement. Truth level for all entries: PLANNED (to be measured on production, then adjusted).

MITRE detection (0.5.0) #

Measurement 2026-10-16 (production, docs/reports/2026-10-16-production-0.5.0-upgrade.md, MEASURED): the credential thresholds were applied unchanged to 44805 failed attempts from 123 IPs; the attempt distribution is bimodal and N=5 separates the groups, 22 IPs stay below the thresholds. The values below are kept; they remain assumptions until the owner decides on tuning.

Per-source-IP credential techniques (backend/hpintel/analytics_jobs.py, aggregate_credential_techniques):

Constant Default Meaning
CRED_WINDOW_HOURS 24 Aggregation window of the housekeeping job (backfill uses consecutive 24 h windows)
CRED_GUESS_MIN_ATTEMPTS 5 N: failed password attempts from one IP; matches the brute_force_threshold default
CRED_GUESS_MIN_PASSWORDS 3 "Several": distinct passwords for at least one username (T1110.001)
CRED_SPRAY_MIN_USERNAMES 5 M: distinct usernames sharing one password (T1110.003)
CRED_SPRAY_BURST_USERNAMES / CRED_SPRAY_BURST_SECONDS 10 / 60 Many distinct usernames in a short time (T1110.003)
CRED_LIKELY_FACTOR 4 Confidence is Likely at 4x a threshold, else Suspected
CRED_MAX_IPS, CRED_MAX_ROWS_PER_IP, CRED_MAX_SESSIONS_PER_IP 500, 20000, 5000 Work bounds per call; a truncation is logged as a WARNING. Housekeeping runs rotate through the candidate IPs (in-process cursor after the last IP of a truncated run); the backfill uses CRED_BACKFILL_MAX_IPS = 5000 per window
CRED_MAX_CANDIDATES 50000 Candidate IPs listed per call

Rows written by this job are rewritten only when the confidence rises; count-only evidence changes are not written.

The window is a function parameter, not an environment setting. Only failed password method attempts are counted. Evidence never contains passwords. All values: to be measured on production.

File-name rules (backend/hpintel/detection.py):

  • T1571 for download URLs: only downloader tools count (DOWNLOADER_TOOLS: wget, curl, tftp, ftpget, ftp, fetch, lwp-download; busybox wget is seen as wget), and the explicit URL port must differ from the scheme default (URL_SCHEME_DEFAULT_PORTS: http 80, https 443, ftp 21, tftp 69). A URL inside echo or another command does not count. Stages starting with shell flow words (then, do, else, elif, if, while, until, !) are parsed without that word.
  • SYSTEM_DAEMON_NAMES (T1036.005) = sshd, systemd, cron, crond, kworker, init, dbus-daemon, rsyslogd. SYSTEM_DIRS = /usr/sbin, /usr/bin, /sbin, /bin, /usr/lib, /lib. A file with such a name that was fetched or created in the session and is executed or made executable outside those directories maps to T1036.005 (Likely). Captured payloads count when their stored name is executed or chmod +x'd.
  • T1564.001 (Likely): a fetched, executed, chmod +x'd or captured file whose path has a component starting with . other than ., .. and the common user dot-names in BENIGN_DOT_NAMES (.ssh, .config, .cache, .local, .aws, .docker, .gnupg, .bashrc, .bash_profile, .bash_logout, .bash_history, .profile, .zshrc, .viminfo, .npm, .cargo, .venv, .git, .vimrc, .bash_aliases, .pki, .wget-hsts, .lesshst). The working directory (cd) is not tracked, so cd .x && ./sshd is not seen as hidden.
  • T1070.004 (Likely): rm, unlink, shred or rmdir of a name (or parent directory) that was fetched, made executable or executed earlier in the same session; wildcards and ., .., empty names are ignored.
