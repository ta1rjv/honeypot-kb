Architecture decisions

ADR 0007: IP intelligence from DNS-based sources

source: docs/decisions/0007-ip-intelligence-sources.md

Status: accepted (2026-10-06)

Decision: Team Cymru IP-to-ASN DNS (ASN, prefix, country, registry, AS name), reverse DNS (switchable with HPINTEL_INTEL_RDNS_ENABLED because PTR queries reach attacker-controlled name servers), optional local MaxMind-format database for city/coordinates. No API keys. Results are labelled "external intelligence" and never treated as identity.

Consequences: requires DNS egress for the backend; geolocation only with a user-provided mmdb file.
