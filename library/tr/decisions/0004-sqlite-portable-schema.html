ADR 0004: SQLite now, PostgreSQL-compatible schema

kaynak: docs/decisions/0004-sqlite-portable-schema.md

Status: accepted (2026-10-06)

Decision: SQLAlchemy Core with portable types, ISO UTC timestamps as text, JSON as text, WAL mode, a versioned migration runner (schema_migrations). Deterministic event ids (UUIDv5 of the raw Cowrie line) make ingest idempotent.

Consequences: single-file database, no extra service; moving to PostgreSQL is a HPINTEL_DATABASE_URL change plus driver (not yet tested).
