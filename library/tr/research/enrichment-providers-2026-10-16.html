yara-python #

yara-python 4.5.4 (Apache-2.0; libyara BSD-3-Clause, SS) has a cp310-cp310-manylinux_2_17_x86_64 wheel (VERIFIED). yara.compile(includes=False) and Rules.match(..., timeout=seconds) are supported (VERIFIED).

YARA rule sources #

No permissively licensed, redistributable ready-made rules for Mirai, Gafgyt, XMRig or shell droppers were found. Avoid: Neo23x0/signature-base (DRL 1.1), Yara-Rules/rules (GPL-2.0), elastic/protections-artifacts (ELv2), YARAHQ/yara-forge (GPL-3.0 aggregate). MIT/BSD sources (reversinglabs-yara-rules, eset/malware-ioc) lack the target families. Decision: ship original in-repo rules.

Sharing formats #

  • TAXII 2.1 (OASIS): /taxii2/ discovery, {api-root}/, collections/, collections/{id}/, collections/{id}/manifest/, collections/{id}/objects/; trailing slashes mandatory; media type application/taxii+json;version=2.1; query added_after, limit, next, match[id|type|version|spec_version]; envelope more, next, objects; error object title plus optional fields (VERIFIED, first 100k characters of the spec read; discovery/collection field lists SS).
  • MISP core format: top-level {"Event": {...}}; Attribute types ip-src, sha256, url valid; tags as {"name": "tlp:..."} at event and attribute level (VERIFIED, draft-dulaunoy-misp-core-format-12).
  • OpenCTI: STIX 2.1 bundle import via the "Import File STIX" connector/UI; built-in TAXII feed ingestion (Data > Ingestion > TAXII Feeds) (SS, docs 6.7/6.8).

PDF fonts #

Adobe Core 14 AFM metrics may be used and redistributed with the Adobe copyright and licence notice kept (mirror: spec.org Adobe-Core14-AFM.txt). Ship the notice with any embedded width table.
