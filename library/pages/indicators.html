Usage note #

  • A source IP seen on a honeypot is a weak indicator on its own: many are rented servers, addresses are reused and scanners rotate. Prefer ASN-level and behaviour-level context.
  • IP geolocation, ASN and reverse DNS are external intelligence about an address, not identity or attribution.
  • Hashes identify files that were pushed to the honeypot. Several hashes can be truncated prefixes of one binary (Group D); compare file families, not only hashes.
  • Attacker URLs and domains are always shown defanged on this site (hxxp://, example[.]com). Never fetch them from a production network.
  • Nothing here is executable content; captured files were never run and are not published.
