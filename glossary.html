Glossary

Term Meaning
Honeypot A decoy system that exists to be attacked and observed. Here: a contained SSH honeypot.
Cowrie Open-source medium-interaction SSH honeypot with an emulated shell; version 3.0.15 is used.
Medium interaction The attacker gets a convincing but emulated shell; commands are not really executed.
Containment The set of controls (default-deny egress, unprivileged users, no tunnels) that stop the honeypot being used against others.
Egress Outbound network traffic from the host.
nftables The Linux packet filter that implements the containment rules.
uid Numeric Linux user id; rules can match traffic by the user that produced it.
Watchdog A mechanism that restarts the honeypot if it stops responding.
Collector The backend component that tails the Cowrie JSON log and ingests events idempotently.
hpintel The name of the FastAPI backend of this project.
WAL Write-ahead logging mode of SQLite.
Session One attacker connection from connect to disconnect.
Payload A file pushed to the honeypot (SCP/SFTP) or written by a command, identified by SHA256.
SHA256 Cryptographic hash used to identify files.
Network intent A network action parsed from a command (for example a wget target); status attempted means the command asked for it, not that a connection happened.
Evidence: observed / derived Observed facts come from Cowrie; derived facts come from parsing commands.
Confidence Suspected < Likely < Observed < Confirmed (see Intelligence pipeline).
Truth level PLANNED, IMPLEMENTED, REVIEWED, VALIDATED, MEASURED, UNKNOWN (see About).
MITRE ATT&CK A public knowledge base of adversary tactics and techniques, with ids such as T1105.
IoC Indicator of compromise: an IP, URL, domain or file hash associated with malicious activity.
Defanging Writing an indicator so it cannot be clicked or resolved by accident (hxxp://, example[.]com).
ASN Autonomous system number identifying a network operator on the internet.
Team Cymru Service that maps IP addresses to ASNs; queried over DNS here.
HASSH A fingerprint of an SSH client or server key-exchange offer.
SFTP / SCP File-transfer protocols over SSH; uploads through them are captured.
Dropper / loader A small program or command that fetches and starts the real malware.
Worm Malware that spreads itself to further hosts.
Credential spraying Trying few passwords against many accounts or hosts.
Brute force Trying many passwords against one account.
XMRig A common open-source cryptocurrency miner, often abused by botnets.
STIX 2.1 A standard JSON format for sharing threat intelligence.
ADR Architecture decision record (see Decisions).
SOC Security operations centre; the dashboard is styled as an analyst console.
Suppression rule A rule that demotes or hides known-noise alerts without deleting them.
Migration bundle An encrypted export of database, settings and honeypot identity for moving to a new server.
VDS Virtual dedicated server, the rented host type used in production.
Pinned address A fixed IP address that a client connects to while still verifying the certificate of the real host name.
